# Проверка каталога — 28 октября 2026

Проверены сборка, публичные карточки, объединение записей, внутренние ссылки,
переводы, поиск, фильтры и мобильный экран. Источники спорных решений перечитаны.

## Исправлено

- **Limoncello di Capri Cream: невеганский.** Производитель указывает молочный крем:
  https://www.limoncello.com/en/crema/.
  Ответ 2015 года на Barnivore описывает обычный лимончелло, а не сливочную версию:
  https://www.barnivore.com/liquor/3824/limoncello-capri-srl.
  Статус, основание и ссылка исправлены только у Cream.
- **Игристые «Лыхны» временно исключены из подтверждённого каталога.**
  https://veganrussian.ru/red-wine-vva/ описывает красные «Апсны» и «Лыхны»;
  отдельного подтверждения для игристой версии в этом источнике нет.
  Это не отрицательный веганский статус. Запись сохранена в исходных данных
  и card_corrections.json для возврата после подтверждения.
- **Fresita объединена в одну карточку игристого напитка.**
  Ранее одна запись попадала в тихие вина, другая — в игристые.
  Производитель: https://www.casalbrands.com/en/productos/fresita-en/.
- **Размер бутылки не определяет отдельный продукт.** Обнаруженные десять
  расхождений между объёмом в названии и полем объёма устранены.
  При нескольких объёмах единый объём не назначается; в отображаемых
  названиях размеры бутылки убраны, исходные названия сохранены.
- **Разная крепость не объединяется автоматически.** Исправлена потеря различий
  между явно указанными крепостями, включая объединение через третью запись
  без крепости. Диапазон 3,4–3,9% сохраняется диапазоном, не становится 3,9%.
  Различия могут относиться к рынку, партии или версии: для последующего
  объединения требуется проверка идентичности.
- **Старые ссылки сохраняются:** добавлены перенаправления для автоматически
  объединяемых записей, включая переход через ручное объединение.
- **ARARAT:** добавлены русские названия четырёх вкусов для поиска
  «Арарат мёд», «Арарат кофе», «Арарат вишня», «Арарат абрикос».
  Ссылки на опубликованные письма подписаны «Ответ производителя».
  По сохранённому каталогу от 25.10 добавлен КуулКлевер / ОТДОХНИ
  для ARARAT 3 звезды, 5 звёзд и AKHTAMAR. Это дата наблюдения каталога,
  а не утверждение о текущем остатке.
- Исправлен устаревший тест привязки сетей: он учитывает проверенные
  объединения и прямые ответы производителей.

## Проверки и защита от повторения

- Все семь Python-проверок и три проверки JavaScript без браузера проходят.
- Новый test_catalog_integrity.py проверяет статусы, подтверждения, размеры,
  диапазоны крепости, локальные ссылки, ID и цепочки перенаправлений.
- Проверки запускаются в GitHub Actions до публикации; ошибка останавливает выпуск.
- В браузере проверены русский поиск медового ARARAT, показ невеганского
  результата через фильтр, источник ответа, английский язык, сохранение карточки
  и фильтров после перезагрузки, совместный фильтр цены и категории,
  старый адрес Hennessy XO и исправленная карточка Cream.
- На ширине 375 px нет горизонтального скролла в проверенных карточках
  и результатах. В проверенных сценариях ошибок JavaScript не было.
