# Поиск и цитирование «Оклейки»

## Что собирается

Команда `python scripts/build.py` автоматически создаёт:

- `drink-<ID>.html`: постоянные страницы каждого активного напитка. Название, статус, основание, область действия, ограничения, даты и источники доступны в исходном HTML.
- `catalog.html`, `catalog-2.html` и далее: каталог по 100 записей с обычными ссылками. На него ведёт ссылка из основного справочника.
- `data/catalog.json`: тот же публичный каталог с именованными полями и адресами страниц. Непроверенные записи, приватная переписка и точные цены не экспортируются.
- `sitemap.xml`: только канонические HTML-адреса, без комбинаций фильтров и без выдуманного lastmod.
- `robots.txt`: публичные страницы разрешены для обхода, указан sitemap. Это разрешение доступа, а не обещание индексации.
- `llms.txt`: краткая карта сайта и описание границ применимости данных.
- Canonical, Open Graph и JSON-LD WebPage/WebSite/Organization на HTML-страницах. На страницах напитков указаны источники через citation.
- Список российских пивоварен в HTML до выполнения JavaScript.

Все новые материалы создаются из уже очищенного публичного экспорта сборки. JSON-LD описывает видимый текст; скрытых рекламных команд для нейросетей нет. Не добавляются рейтинги, предложения о продаже или выдуманные сертификаты.

Русский — язык исходного HTML. Существующий английский интерфейс работает через JavaScript; фиктивные hreflang для несуществующих самостоятельных английских HTML-версий не добавляются.

## Проверки

Сборка и все `scripts/test_*.py`, а также `scripts/test_*.cjs` кроме `*_ui.cjs` выполняются в GitHub Actions.

Дополнительно `node scripts/test_search_ui.cjs` проверяет desktop/mobile, RU/EN, возрастное окно, переходы, canonical и чтение без JavaScript. Требуется Playwright и Edge. `SEO_SCREENSHOT_DIR` задаёт существующий каталог для скриншотов.

## После публикации

В Google Search Console для подтверждённого владельцем домена добавить sitemap:
https://okleika.win/sitemap.xml

Через «Проверка URL» проверить главную, каталог и несколько карточек, затем при необходимости запросить индексацию. Подтверждение владения требует доступа к аккаунту владельца или DNS; этот репозиторий сам по себе не даёт такого доступа. Аналогично sitemap можно передать в Bing Webmaster Tools.

Измерять показы, клики, индексируемые страницы и запросы в Search Console; переходы от ИИ — по реферерам в доступной аналитике. Сохранить базовые показатели до сравнения. Не считать успешный HTTP 200 доказательством индексации или цитирования.

Индексация и выбор источника зависят от поисковых систем. llms.txt является дополнительным предлагаемым форматом, а не обязательным протоколом или гарантией рекомендаций.
