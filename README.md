# Оклейка

Независимый справочник веганского статуса алкоголя в каталогах российских сетей.
Сайт: https://frieddum.github.io/okleyka/

Это статический сайт без сервера, базы данных и аналитики. Он собирается из одного
публичного файла `data/snapshot.json`. Проект не связан с Barnivore, торговыми сетями
и производителями.

## Как обновить данные

1. Подготовьте новый публичный снимок с той же схемой (поля `as_of`, `counts`, `verified`
   и пояснения `*_note`) и запишите его в репозиторий без непроверенных позиций:
   ```
   python scripts/build.py --trim путь/к/новому_снимку.json
   ```
   Команда перезапишет `data/snapshot.json`, выбросив раздел `unmatched`.
2. Проверьте сборку локально:
   ```
   python scripts/build.py
   python -m http.server 8000 --directory _site
   ```
   и откройте http://localhost:8000.
3. Сделайте коммит и отправьте его в ветку `main`. GitHub Actions соберёт сайт и опубликует
   его на Pages (вкладка Actions → «Сборка и публикация»).

Сборка остановится с ошибкой, если в файле найдутся адреса почты, локальные пути,
токены или ссылки вне поля источников (`assessment.references[].url`). В публикацию попадают
только поля из белого списка в `scripts/build.py`: новые поля в JSON на сайт сами не попадут.

## Сводный каталог сетей

Второй источник — сводный каталог сетей (`catalog_public.json`) с выгрузкой Barnivore (`companies.jsonl`).
Он импортируется отдельно, по тем же правилам, что и снимок:

```
python scripts/import_catalog.py путь/catalog_public.json путь/barnivore_export/companies.jsonl
```

Скрипт пишет `data/catalog_extra.json` (только публикуемые позиции, без цитат) и
`data/barnivore_companies.json` (адрес страницы Barnivore → компания). Правила отбора, решения
по компаниям и найденные ошибки сопоставления записаны в начале `scripts/import_catalog.py`.
Приватный реестр (`catalog_private.xlsx`) в репозиторий не кладётся и не используется.

## Пересмотр решений

`data/overrides.json` — решения, пересмотренные поверх снимка: статус, основание и область действия.
Запись находится по сети и точному названию из снимка, поэтому при замене снимка файл не нужно
переписывать. Если записи больше нет, сборка напишет предупреждение. В карточке такой записи
отмечено, что решение пересмотрено.

## Устройство

- `scripts/build.py` проверяет снимок, берёт только записи с сохранённым решением (`verified`),
  объединяет только полностью одинаковые строки одной сети и пишет компактные файлы в `_site/data/`.
  Непроверенные позиции каталогов (`unmatched`) не публикуются и не используются, даже если
  оказались в файле.
- `site/` содержит страницы, стили, скрипт поиска и шрифты (Golos Text и Old Standard TT, SIL OFL 1.1).
- Поиск работает в браузере: индекс строится при загрузке, выдача разбита на страницы.
- Ссылки на карточки имеют вид `?id=…`. Идентификатор вычисляется из данных записи и не меняется,
  пока не меняется сама запись.

## Источники

Часть решений опирается на страницы barnivore.com. По условиям сайта у каждой такой
записи указаны ссылка на исходную страницу и дата сверки.


## Языки интерфейса

Переключатель Русский / English доступен на всех страницах и в окне 18+. Выбор хранится локально и передаётся параметром `lang=ru` или `lang=en`; явный параметр ссылки имеет приоритет. Поиск, фильтры и ID карточки сохраняются при переключении. Интерфейс переводится через `site/i18n.js`, содержимое каталога и ответы пивоварен — через `data/translations_en.json`. Поиск индексирует оба языка. Перевод не меняет исходные решения, ограничения, ссылки и значения фильтров. Сборка проверяет покрытие словаря и создаёт локальный `content-en.js`; внешние сервисы перевода при просмотре сайта не вызываются. При обновлении каталога добавьте переводы новых строк. Проверка: `node scripts/test_i18n.cjs`.
