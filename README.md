# Оклейка

Независимый справочник веганского статуса алкоголя в каталогах российских сетей.
Сайт: https://frieddum.github.io/okleyka/

Это статический сайт без сервера, базы данных и аналитики. Он собирается из одного
публичного файла `data/snapshot.json`. Проект не связан с Barnivore, торговыми сетями
и производителями.

## Как обновить данные

1. Замените `data/snapshot.json` новым публичным снимком с той же схемой
   (поля `as_of`, `counts`, `verified`, `unmatched` и пояснения `*_note`).
2. Проверьте сборку локально:
   ```
   python scripts/build.py
   python -m http.server 8000 --directory _site
   ```
   и откройте http://localhost:8000.
3. Сделайте коммит и отправьте его в ветку `main`. GitHub Actions соберёт сайт и опубликует
   его на Pages (вкладка Actions → «Сборка и публикация»).

Сборка остановится с ошибкой, если в файле найдутся адреса почты, локальные пути,
токены или ссылки вне поля источников (`assessment.references[].url`). В публикацию попадают
только поля из белого списка в `scripts/build.py`: новые поля в JSON на сайт сами не попадут.

## Устройство

- `scripts/build.py` проверяет снимок, объединяет только полностью одинаковые строки одной сети
  и пишет компактные файлы в `_site/data/`.
- `site/` содержит страницы, стили, скрипт поиска и шрифты (Golos Text и Old Standard TT, SIL OFL 1.1).
- Поиск работает в браузере: индекс строится при загрузке, выдача разбита на страницы.
- Ссылки на карточки имеют вид `?id=…`. Идентификатор вычисляется из данных записи и не меняется,
  пока не меняется сама запись.

## Источники

Часть решений опирается на страницы barnivore.com. По условиям сайта у каждой такой
записи указаны ссылка на исходную страницу и дата сверки.
